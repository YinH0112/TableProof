# v0.1 release checklist

Record dated evidence in verification.md; a check is incomplete until run.

- Backend coordinates, edits, persistence failure, cancellation, conflicts and XLSX tests pass.
- TypeScript build and Chromium tests pass against built offline app.
- Windows portable starts and completes a sample workflow without Python/Node on PATH.
- PDF assets and licenses ship; no non-loopback request during daily workflow.
- ZIP includes startup script and bilingual docs, MIT and third-party notices.
- Open workbook in Excel and LibreOffice if available; record unavailable apps rather than claiming pass.
- Independently review paper annotations before extraction-accuracy claims.
- Complete five-person trial before any 30% productivity claim.
- Prepare screenshot/demo and known limitations.
- External publication, promotion and participant invitations require user authorization after preparation.
